# VERIFIED POSTS — ARCHIVE

Every post that has been verified (voice-checked, banned-word-free,
final-approved for publication) gets its own folder here.

## Folder Naming Convention

    YYYY-MM-DD_<short-slug>_<pillar>_<style>

Example:

    2026-08-19_stop-tutorial-hell_SE_FRAME/

Each folder contains:

| File | Purpose |
|---|---|
| `post.md` | The final approved LinkedIn post text |
| `hooks.md` | All 5 hook options that were generated |
| `metadata.json` | Pillar, style, hook type, predicted performance, best time, hashtags, CTAs |
| `visual_brief.md` | (Optional) Design brief for Canva/poster/carousel |
| `amplification/` | (Optional) X thread, standalone tweets, Substack expansion |
| `publish_log.md` | When it was posted, link, first 24h metrics |

## Workflow

1. Draft → voice check → banned words check → revision
2. Once you approve ("verified"), create the dated folder
3. Drop in `post.md` + supporting files
4. Commit & push
5. Append a one-line entry to `INDEX.md` below
