# Hook Options — 2026-09-23 "clever code tax" post

## RECOMMENDED HOOK (USED)
"Funny enough — the worst code I ever wrote was the code I was proud of."
- Type: Counter-intuitive confession (the code you're proud of is the dangerous code)
- Uses voice DNA "Funny enough…" opener — natural, disarming
- Immediately contradicts the "write elegant code" advice everyone parrots

## ALT 1
"I wrote the cleverest function of my career last year. We deleted it last week."
- Bold, specific, has a cost baked in (deleted it)
- Strong stop-scroll for engineers

## ALT 2
"Clever code is not a feature. It's a tax."
- One-line thesis opener; punchy, quotable
- Higher risk: feels more like a hot take, less like a story

## ALT 3
"Let me tell you about the abstraction that cost my team two weeks."
- Cost-led opener (names the damage upfront)
- Works but less universal than the confession hook
