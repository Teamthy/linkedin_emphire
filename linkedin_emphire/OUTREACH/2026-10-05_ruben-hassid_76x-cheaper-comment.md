The 76x framing is the cleanest version of this argument I have seen. One edge nobody mentioned though: if intelligence gets 76x cheaper every year, so does attacking with it.

The same curve that lets a solo builder in Lagos ship an agent lets anyone generate ten thousand injection variants for pennies. Defense is not on that curve. Models get cheaper on a schedule. Testing discipline only gets cheaper when teams build the habit, and nothing about the price forces that.

So the question is not whether AI is a bubble. It is what happens when every product ships on a component whose failure modes change with every model release. Cheaper intelligence means more agents with hands on real data, and a wider blast radius for the same old mistakes.

Cheap intelligence is an opportunity. It is also a cheaper weapon. Both stay true.
