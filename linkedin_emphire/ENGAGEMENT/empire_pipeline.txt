STEP 2.1: Engagement Round
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
INPUT: comment_surfaces.md + reply watchlist
AGENT: Engagement Specialist

PROMPT:
"Pick today's 5-8 comment actions from the surface
list (fresh posts only: same day or yesterday).

[PASTE 5-8 FRESH POSTS FROM SURFACES]

SOURCE RULE first (comment_surfaces protocol 9, 10-24 owner
standing instruction): if a post carries a read-more, article,
paper, or report link, fetch and read the full source before
drafting anything. Comment on the source, cite specifics to the
source, and prefer the one finding the post omitted as the
added value. If the source cannot be fetched, mark the draft
UNVERIFIED-SOURCE in the tone notes.

PROFILE READ + method before the mode (comment_surfaces
protocol 10, 10-24 owner direction): for each pasted surface,
read the author's block from the paste (relationship, degree,
headline, commercial signals, tier, thread-partner status from
the published_comments archive) and pick the move from the
method ladder: reply / follow-back + comment / comment /
repost with thought / skip. Missing fields are UNKNOWN, not
guessed. Method before mode. A repost replaces the comment on
the same surface, it never stacks with it.

Pick the mode first (ENGAGEMENT/voice_dna.txt
COMMENT MODES, 10-24 fine-tune):
- tier 1-2 surface, no checkable claim
  → OUTSTANDING (expertise + risk angle,
    90-120 words, one memorable line allowed)
- post contains a checkable claim or number
  → QUESTIONING (90-120 words, lead with the
    line that does not hold, one re-runnable
    counter, argue the checkable part only)
- personal, community, or celebration post
  → HUMAN (20-80 words, warm, specific, frame
    invisible, no memorable-line attempt)
- a reply is due on any thread → INTERACTIVE
  (15-60 words, question allowed there only)

For each, provide:
- 2 options inside the picked mode (different
  angles, same risk level), one idea per breath
- Recommended option with reason
- One memorable line called out (OUTSTANDING
  only; HUMAN mode gets none)
- Tone notes
- SLOP DETECTOR result (voice_dna.txt PART 10):
  0 em dashes, 1-4 contractions (none in the
  first line), word count inside budget and
  under the post's length, argument test passed,
  no CATEGORY 7 openers or closers, uneven
  paragraphs, no bullets, flat ending

Also draft any follow-up replies due from the
watchlist, INTERACTIVE mode (hostile reply
protocol: do not defend, serve the verifiable
claim, invite the re-run)."

GATE BEFORE POSTING (every single comment,
search the text for each):
□ 0 em dashes. Contractions 1-4, none in the
  first line, none doubled in one clause
□ Word count inside the mode budget and under
  the post's length
□ Argument test: at least one line a hostile
  reader could argue with
□ Compliment check: at most one, specific
  (the author must be able to point at the
  line), never the first line; required as the
  payload in HUMAN mode (COMPLIMENT RULE,
  voice_dna.txt PART 10)
□ No CATEGORY 7 openers or closers
  (banned_words.txt)
□ Uneven paragraph lengths, no bullets
□ Flat ending (question mark only in
  INTERACTIVE mode), no hashtags
□ No two of today's comments reuse the same
  closer
□ Read it aloud once: any sentence that sounds
  like a caption gets rewritten

HUMAN ACTION: Review, edit, post manually, spaced
