# ENGAGEMENT/published_comments/

Verbatim archive of the owner's PUBLISHED LinkedIn comments and replies, in the owner's
voice, with metrics at capture. This is the record of what actually shipped, not the
drafts (drafts live in conversation history and in response_templates conventions).

## Convention
- One file per capture window: `YYYY-MM-DD_to_YYYY-MM-DD_verbatim.md`.
- Entries: author, post topic, relative age, impressions, text as displayed (mention
  prefixes kept), context line only where attribution is non-obvious from the feed.
- Metrics are point-in-time; refresh by re-pasting the activity feed, never by editing
  earlier entries.
